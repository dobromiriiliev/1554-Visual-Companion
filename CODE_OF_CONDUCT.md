# Community Code of Conduct

We want this project to be useful to learners and welcoming to contributors.

## Expected behavior

Participants should:

- discuss ideas and code rather than attacking people;
- assume good faith while still correcting mathematical or technical errors clearly;
- give actionable feedback;
- respect different levels of mathematical and programming experience;
- avoid harassment, discrimination, threats, sexualized conduct, or targeted humiliation;
- protect private information shared accidentally;
- respect project licensing and attribution rules.

## Educational discussions

It is acceptable to say that an explanation, proof, or animation is incorrect. Be specific about *what* is incorrect and how it can be improved.

Do not use expertise as a reason to belittle beginners.

## Scope

This policy applies to repository issues, pull requests, discussions, project chat spaces, and other spaces explicitly operated by the project.

## Reporting

If the repository enables private moderation or security contact channels, use those for sensitive reports. Otherwise contact a maintainer privately rather than posting personal or sensitive details in a public issue.

## Enforcement

Maintainers may edit or remove harmful content, close discussions, temporarily restrict participation, or permanently remove access when necessary to protect the community.
