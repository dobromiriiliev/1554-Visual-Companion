# Attribution and Intellectual-Property Boundaries

This repository is intentionally designed to be open source without republishing other educational creators' content.

## Georgia Tech MATH 1554 notes

The public MATH 1554 notes are used as a **curriculum-order and learning-objective reference**. This project links to the original sections rather than copying their prose.

Original examples and original explanatory language should be used in this repository.

Georgia Tech names and course identifiers are used only to describe curriculum alignment. This project is unofficial and is not endorsed by Georgia Tech.

## 3Blue1Brown

The project's visual teaching philosophy is influenced by the broader success of geometric mathematical explanation, including 3Blue1Brown.

This repository does **not** include or license:

- 3Blue1Brown video footage;
- scripts or narration;
- thumbnails or branding;
- Pi creatures or other protected visual assets;
- copied scene compositions.

Contributors should create original animations.
