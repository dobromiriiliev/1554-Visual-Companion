# Curriculum map

The machine-readable curriculum map is `course_map.yaml`.

## Chapter 1 narrative

Chapter 1 progressively changes the *representation* of the same underlying linear-algebra ideas:

1. **Systems** — simultaneous constraints.
2. **Row reduction** — equivalent systems and pivots.
3. **Vector equations** — weighted combinations of vectors.
4. **`Ax=b`** — matrix-vector notation for those combinations.
5. **Solution sets** — parameterized geometric families.
6. **Linear independence** — whether directions are redundant.
7. **Linear transformations** — matrices as functions on vectors.

This narrative is why animations should not be treated as isolated clips. Later scenes should visually reuse ideas established earlier.
