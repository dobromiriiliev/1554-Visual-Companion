# For students

The best way to use this project is as a **second representation**, not as a replacement for solving problems.

## Suggested workflow

1. Read the relevant course-note definition or theorem.
2. Watch the matching short scene.
3. Explain the visual in your own words.
4. Return to the algebra and identify which symbols correspond to what you saw.
5. Solve a fresh problem without the animation.

## Questions to ask while watching

- What is changing?
- What remains invariant?
- What geometric object represents the solution set?
- What does a pivot mean visually here?
- What does a free parameter let me move along?
- What object does a column of a matrix represent?
- Which directions are redundant?

## Avoid passive watching

An animation can make an idea feel obvious without making it retrievable. Pause and predict the next state before the animation shows it.

## Exam preparation

Use the visual scenes to rebuild intuition, then practice the exact symbolic procedures and proof language required by your course.
