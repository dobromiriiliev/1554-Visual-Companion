# For educators

Scenes are designed to be short, modular teaching objects rather than complete lecture videos.

## Classroom uses

- introduce a concept before formal notation;
- pause after a prediction prompt;
- use a scene as a recitation warm-up;
- place a rendered clip beside a worked example;
- ask students to narrate what an animation is showing;
- compare two representations of the same system.

## Recommended pattern

```text
question -> prediction -> animation -> formal statement -> computation
```

The prediction step matters. It keeps the visualization from becoming passive entertainment.

## Adapting scenes

You are encouraged to fork or modify scenes under the MIT License. When changing notation, preserve the underlying conceptual objective and document the adaptation.

## Course alignment

The repository links to public MATH 1554 sections but deliberately uses original examples. Instructors should treat the upstream course notes as the source of truth if course content changes.
