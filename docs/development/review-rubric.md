# Scene review rubric

Use this rubric for new scenes and substantial visual revisions.

## 1. Mathematical correctness — required

- [ ] Every equation and transformation is correct.
- [ ] The visual does not suggest a false generalization.
- [ ] Special cases are labeled when they are special cases.
- [ ] The final symbolic statement matches the visual state.

A failure here blocks merge.

## 2. Learning objective — required

- [ ] The scene has one primary objective.
- [ ] The class docstring states that objective clearly.
- [ ] A student can explain what relationship the motion is intended to show.

## 3. Visual-semantic alignment

- [ ] Motion represents mathematical change.
- [ ] Objects that persist mathematically persist visually when practical.
- [ ] Invariants are visibly stable.
- [ ] Layout makes comparisons easy.

## 4. Symbolic reconnection

- [ ] The scene connects back to an equation, vector, matrix, theorem, or computation.
- [ ] Notation does not appear as an unrelated afterthought.

## 5. Accessibility

- [ ] Meaning does not depend on color alone.
- [ ] Text is readable at ordinary video size and classroom projection.
- [ ] Important states have sufficient dwell time.
- [ ] Motion is not unnecessarily rapid or distracting.

## 6. Maintainability

- [ ] The scene uses shared theme constants.
- [ ] Repeated logic is understandable.
- [ ] New abstractions are justified by actual reuse.
- [ ] Public scene names are descriptive and stable.

## 7. Originality / licensing

- [ ] The example and explanation are original or appropriately licensed.
- [ ] No third-party media is included without documented permission or compatible licensing.
- [ ] The scene does not copy a 3Blue1Brown composition or protected visual asset.

## Recommended review result

Reviewers can summarize with:

- **Correctness:** pass / changes required
- **Pedagogy:** strong / adequate / unclear
- **Accessibility:** pass / changes required
- **Maintainability:** pass / changes required
- **Render evidence:** reviewed / not reviewed
