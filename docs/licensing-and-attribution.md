# Licensing and attribution

## Project code

The repository's original code and original documentation are licensed under MIT unless a file explicitly says otherwise.

## Georgia Tech course notes

The project links to public MATH 1554 notes to describe curriculum alignment. Do not copy substantial note text into this repository. Write original explanations and examples.

## Manim

Manim Community Edition is an open-source animation framework under MIT licensing. The project depends on Manim but does not bundle the Manim source code.

Upstream:

- <https://github.com/ManimCommunity/manim>
- <https://docs.manim.community/>

## 3Blue1Brown

Manim's openness does not mean that every asset from 3Blue1Brown videos is a reusable project asset. This repository therefore avoids copying video footage, narration, characters, thumbnails, branding, and scene compositions.

Create original visual explanations.

## Third-party contributions

Any future media or asset contribution must include:

- source;
- author or owner when known;
- license;
- reason the license is compatible with the repository.
