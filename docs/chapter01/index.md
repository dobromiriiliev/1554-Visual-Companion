## Narrative arc

### 1.1 — Constraints and intersections

Start with equations as sets of possible points. A system asks which points satisfy all constraints simultaneously.

### 1.2 — Equivalent descriptions

Row reduction changes the representation while preserving the solution set. Pivots and free variables become structural information.

### 1.3 — Weighted directions

Reframe the same algebra as vector addition and scalar multiplication. Span becomes a reachable set.

### 1.4 — Package the combination

`Ax=b` compresses a column combination into matrix notation and ties existence to the column span.

### 1.5 — Whole families of solutions

Free variables stop being merely "variables without pivots" and become parameters that move through geometric solution sets.

### 1.7 — Redundancy

Linear independence asks whether any direction can be built from the others.

### 1.8 — Matrices as functions

The matrix now acts on *every* input vector. Earlier ideas about span, pivots, existence, and uniqueness reappear as properties of a transformation.
