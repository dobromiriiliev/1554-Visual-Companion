# Accessibility

Mathematical animation should not require perfect color vision, hearing, or fast visual processing.

## Color

Never use color as the only signal. Pair color with at least one of:

- labels;
- line style;
- position;
- shape;
- explicit notation.

## Motion

- avoid unnecessary rapid camera movement;
- give important final states enough dwell time;
- avoid flashing or strobing effects;
- keep simultaneous motion limited when several objects must be tracked.

## Text

- use strong contrast;
- keep classroom projection in mind;
- avoid tiny explanatory paragraphs;
- use concise language.

## Captions and narration

Rendered videos should eventually include either captions, narration transcripts, or sufficient on-screen context to understand the central mathematical idea.

## Documentation

Each scene's README or catalog entry should state its learning purpose so users can understand the clip even when they cannot consume every visual detail.
