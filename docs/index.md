# MATH 1554 Visual Companion

**See the geometry at the same pace as the course.**

The MATH 1554 Visual Companion is an unofficial, open-source collection of Manim scenes aligned to the public Georgia Tech MATH 1554 course sequence.

Chapter 1 currently contains **42 short scenes across seven published sections**.

## What makes it different?

Many visual linear-algebra resources are organized around their own narrative. Many course notes are optimized for concise symbolic reference. This project occupies the layer between them.

```text
MATH 1554 objective
       ↓
visual question
       ↓
short Manim scene
       ↓
formal notation / computation
```

The animation is not the endpoint. It is a bridge back to the mathematics a student must read, compute, and explain.

## Example conceptual bridges

| Course idea | Visual bridge |
|---|---|
| Consistency | Intersections of geometric constraints |
| Row reduction | Change representation while preserving solutions |
| Span | Reachable points from weighted vectors |
| `Ax=b` | Build `b` from columns of `A` |
| Free variables | Directions of motion through a solution set |
| Independence | Whether a direction is redundant |
| Linear transformation | Move an entire grid while preserving linear structure |
