# Security Policy

This is an educational animation project and is not intended to process secrets, credentials, or sensitive user data.

## Supported versions

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

If you discover a vulnerability that could meaningfully affect users—for example unsafe command construction, dependency misuse, or a workflow that could expose repository secrets—please use GitHub's private security advisory feature if it is enabled.

Do **not** place credentials, tokens, private student data, or exploit details in a public issue.

## Out of scope

Ordinary mathematical mistakes, visual bugs, installation issues, and rendering failures are not security vulnerabilities. Please report those through the normal issue templates.
