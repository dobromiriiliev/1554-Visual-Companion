# Support

## Installation problem

Run:

```bash
python scripts/doctor.py
```

Then open a bug report with:

- operating system;
- Python version;
- Manim version;
- the command you ran;
- the complete error output;
- whether `ffmpeg` and `latex` are available.

## Mathematical question

Use a discussion or issue only when the question is about how a scene represents course material. This repository is not intended to replace ordinary course tutoring channels.

## Scene request

Use the **Visualization request** issue form. Describe the concept, the misconception or intuition gap, and the relevant course section.

## Course alignment issue

Use the **Course alignment** issue form when a scene no longer matches the public course sequence, notation, or learning objectives.

## Manim-specific problem

If the issue reproduces independently of this repository, consult the Manim Community documentation and issue tracker.
